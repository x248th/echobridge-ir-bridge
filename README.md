# echobridge-ir-bridge

EchoBridge 本体の **赤外線アドオン**。
本体が管理している照明とシーンを、赤外線リモコンの信号で操作できるようにする。

- スマートリモコンに、シーンや照明ごとの赤外線コードを学習させる（本機が送信する）
- お手持ちのリモコンのボタンを、シーンに割り当てる

本機が受信した赤外線に応じて、本体のシーン発火・照明の明るさ設定を行います。

## 必要なもの

- EchoBridge 本体が **同じ機体で** 稼働していること（`:8099`）
  - 本体を別の機体に置く構成には対応していません
- 赤外線の送受信機（**別途用意が必要です**）
  - 動作を確認しているのは Irdroid（USB 接続・送受信兼用）です
  - 送信には `ir-ctl`（パッケージ `v4l-utils`。Raspberry Pi OS には標準で入っています）を使います
- Python 3.10 以上（標準ライブラリのみで動作し、追加のパッケージは不要です）
  ※Raspberry Pi OS なら Bookworm 以降。Bullseye の Python 3.9 では動作しません。

## 導入

本体の管理画面から、赤外線アドオンの **インストール** ボタンで導入します。
起動・停止も本体の管理画面から行います。

## 設定

設定は、本機が開く専用の設定画面で行います。
**本体の管理画面の、赤外線アドオンのカードにある「設定画面を開く」から開けます。**

同じネットワークにつながっているパソコン・タブレット・スマートフォンから、
直接このアドレスを開くこともできます。

```
http://<本機のアドレス>:8100/
```

学習のしかた・置き場所・うまくいかないときの切り分けは、設定画面の中に書いてあります。

- **設定画面にパスワードはかかっていません。** 同じネットワークに接続できる人は誰でも
  開くことができ、**設定の変更や赤外線の送信もできます**。受信ログ（いつ、どのボタンの
  信号を受けたか）も見られます。
- 赤外線の届く距離や向きは、機種と設置場所によって変わります。
- 設定（プリセット・明るさの候補・リモコンの割り当て）は `~/addon-data/ir-bridge/` に保存され、
  **アンインストールしても残ります**。
  設定を消すには、アンインストールしたあと、本体の管理画面の赤外線アドオンのカードに出る
  「残っている設定を削除」を押します。（本体の「アドオンをすべて削除」は、**ほかのアドオンの
  設定もまとめて消す**ので、この用途には使わないでください。）

## サポート範囲

- 扱う赤外線の形式は NEC 系（`nec` / `necx` / `nec32`）のみです。
  それ以外の形式のリモコンは、ボタンを割り当てられません。
- 本機が送信する学習用のコードは、市販のリモコンと重ならないように選んでいますが、
  重ならないことを保証するものではありません。重なった場合は、設定画面の詳細設定で
  コードの組み合わせ（プリセット）を切り替えられます（切り替えると学習し直しになります）。
- 動作を確認していない赤外線機器・スマートリモコンについては、動作をお約束できません。
